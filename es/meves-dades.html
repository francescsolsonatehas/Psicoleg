Tus datos

Mis datos y recordatorios

Todo lo que apuntas en las herramientas se guarda solo en tu navegador. Aquí puedes imprimirlo, hacer una copia o preparar recordatorios para la agenda.

📦 Qué tienes guardado

    Los datos viven solo en este navegador y dispositivo. Si borras los datos del navegador, se perderán: por eso conviene hacer una copia.

    🖨️ Para llevar a la consulta

    Genera un resumen legible para enseñar a tu médico o psicólogo. Puedes imprimirlo, guardarlo como PDF o descargarlo como texto.

    ¿Qué quieres incluir?

    💾 Copia de seguridad

    Descarga un archivo con todos tus datos, o recupera uno anterior (por ejemplo en otro dispositivo).

    Al importar…

    ⏰ Recordatorios suaves para la agenda

    Esta web no envía notificaciones. Puedes descargar un archivo de calendario (.ics) y abrirlo con tu calendario (Google, Apple, Outlook…) para que te lo recuerde él.

    El archivo solo contiene un título amable y un enlace a esta web, nunca tus datos.

    🗑️ Borrarlo todo

    Elimina de forma definitiva todos los datos de las herramientas de este navegador. No se puede deshacer.
