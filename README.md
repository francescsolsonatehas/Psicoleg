# Psicòleg

Web de salut mental en català: fitxes psicoeducatives (16 trastorns i condicions), eines d'autoajuda (respiració, grounding, relaxació, registre d'ànim, diari de pensaments), cribratges PHQ-9 / GAD-7 i recursos d'ajuda a Catalunya.

- HTML + CSS + JavaScript pur, sense build ni dependències.
- Tipografies pròpies (Inter, Poppins; SIL OFL), sense peticions a tercers.
- Sense comptes ni cookies: els registres es guarden només al navegador (localStorage).
- Barra d'ajuda urgent (112 / 024) visible a totes les pàgines.
- Mode clar/fosc, mida de text ajustable, accessible i amb `prefers-reduced-motion`.

Publicat amb GitHub Pages: https://francescsolsonatehas.github.io/Psicoleg/

> Contingut informatiu. No substitueix un professional sanitari. Cal que un psicòleg o psiquiatre col·legiat revisi el contingut clínic abans de difondre'l, i completar les dades del titular a `avis-legal.html`.
