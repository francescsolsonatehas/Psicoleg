Your data

My data and reminders

Everything you note in the tools is stored only in your browser. Here you can print it, make a backup or set up reminders for your calendar.

📦 What you have stored

    The data lives only in this browser and device. If you clear the browser’s data, it will be lost: that is why a backup is a good idea.

    🖨️ To take to your appointment

    Generates a readable summary to show your doctor or psychologist. You can print it, save it as a PDF or download it as text.

    What would you like to include?

    💾 Backup

    Download a file with all your data, or restore an earlier one (for example on another device).

    When importing…

    ⏰ Gentle reminders for your calendar

    This website does not send notifications. You can download a calendar file (.ics) and open it with your calendar (Google, Apple, Outlook…) so that it reminds you.

    The file only contains a friendly title and a link to this website, never your data.

    🗑️ Delete everything

    Permanently deletes all the tool data in this browser. This cannot be undone.
